# Barraca Uno
React + TypeScript, Tailwind CSS y Sites. Catálogo de 12 materiales con fotografías ilustrativas, filtros, vistas de tarjetas/tabla y órdenes con IVA 22%.

Incluye temas oscuro/claro/sistema, acceso local y con proveedores, sesiones JWT firmadas, perfiles persistentes en Cloudflare D1, avatar, acento y densidad personalizados.

Consultá GUIA-CUENTAS.md y /guia para usar la cuenta, comprender la base de datos y probar el proyecto localmente. /creditos documenta las fotografías y sus licencias.

Los materiales y órdenes son de demostración. Las órdenes se mantienen en la sesión de la página y no se envían ni guardan. Los perfiles se guardan en D1 y están asociados a la identidad autenticada.

Verificación: pnpm exec tsc --noEmit y pnpm build.
